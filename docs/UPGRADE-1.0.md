# 1.0.0：持续共同设计的里程碑

这次把架构工作中反复依靠聊天记忆、手工转录和旧日志完成的步骤，接入可恢复、可核对的工作流程。版本从 1.0.0 开始记录这一里程碑；既有框图风格与 IR 1/2/3 兼容保留。

## 五项实现

| 过去的阻力 | 1.0 的实际行为 |
|---|---|
| 图上问题离开聊天就失去上下文 | 模块/连线问题持久保存，context 读取，答复关联候选，用户核对解决；目标与下一步可以恢复 |
| 已有 RTL 的层级和连接需要大量手抄 | 读取 Yosys 展开 JSON，生成部分模型和源码映射；改动后报告重核实例，重新导入保留稳定路径 ID |
| 方案取舍只停留在文字 | 同一计算器比较计算资源、存储端口和缓存容量，保存配置、工作量、假设与历史；显示条件化下界 |
| 一处修改要求所有模块重审 | 依赖指纹保留无变化的模块确认；变更模块显示原因、可跳到下一个待复核对象；整体批准仍绑定当前模型 |
| 不知道该开哪个页面、结果是否陈旧 | open 核对源码、构建和服务，按需构建，恢复继续位置；verify 保存独立运行、重新核对输入和报告 |

用户在“讨论与继续”中保存问题，回到 Codex 让它处理；网页不会自己调用模型。Agent 的答复与候选记录在同一工作台，用户不需要重复交代原对象，也不用编辑 JSON。

## 计算与验证各自说清楚

预算把运算服务量与存储端口需求取最大，给出平均服务间隔、总周期的下界；缓存需求按持续产生量、停顿和在途量计算。缺少端口、容量不足或整数溢出不会生成“可行”结论。保存后的预算保留原假设，修订使用新 ID。

计算要求独立资源与阶段重叠等前提；递推依赖、银行冲突、仲裁和共享单端口不能套用成精确性能。预算结果不等于实测 II、延迟、面积或频率。关联运行也不自动证明某个数值。

![历史验证摘要](evidence/1.0.0/README.md)

verify 使用显式输入清单和 argv，在每次新的目录保存工具版本、输入、日志、报告摘要和结果。支持退出状态、明确成功标志与 JUnit 实际用例检查；空报告、失败、跳过、超时、输入运行中变化和报告越界不能通过。没有自动发现传递依赖，没有网页任意执行入口，也不会自动批准或重写 IR 验证声明。

## 从 RTL 开始及按影响复核

首个适配器限定为 Yosys `write_json`：层级实例、单向端口、明确位连接和常量；保留原 RTL 名、位序及源文件映射。内部运算、存储行为、周期、双向或多驱动缺口不会凭空补齐。输出始终是 as_built / partial，不能直接批准交接。详见 [可复现 RTL 样例](../examples/rtl-intake/README.md)。

模块确认指纹涵盖本模块子树、相关连接与内部驱动、相邻合同、祖先环境、相关需求及全局时钟/来源。影响范围不明时保守扩大；没有指纹的旧确认在模型变化后重新核对。源码映射只说明重核范围，不证明语义等价。

## 使用与升级

```bash
# 目标项目无模型时，显式允许初始化；已有模型不覆盖
rtlarch open --init --workspace /path/to/rtl
# 下一次继续
rtlarch open --workspace /path/to/rtl
rtlarch resume --workspace /path/to/rtl --json
# 更新工具后，只重启自己的工作区
rtlarch open --restart --workspace /path/to/rtl
```

open 自动构建缺失或过期页面，不自动安装依赖；浏览器打开失败则返回可复制地址。`--json` 只返回结构化结果。重启前保存页面未发送的文字；已保存的工作记录会恢复。历史 HTML 是快照，必须另行 bundle 生成新目录。

图上讨论不会改变模型或布局。展开工作台、切换侧栏及窗口大小时，画布保持中心和缩放；选中对象会在层级树中展开，审阅模块时保持审阅面板。

## 本轮证据与边界

[完整验证](../VALIDATION.md) · [历史验证摘要](evidence/1.0.0/README.md) · [历史验证摘要](evidence/1.0.0/README.md)。

在已有构建的本机临时环境中，原始 RTL 到可浏览候选约 **6.6 秒**，服务停止后恢复问题/候选/继续位置约 **3.1 秒**，含编译的 RTL 自检约 **7.4 秒**。完整自动流程约 27.2 秒、15 次 CLI 调用；恢复不重新录入已保存上下文。模型有 3 个实例和 10 条连接；改变 stage.sv 后两个实例进入重核范围，旧运行失效。

这些是自动流程的实测时间，不是人类理解速度、任意项目的耗时保证或效率提升百分比。未宣称支持任意 RTL 自动完整还原；未执行综合、STA、formal、真实 Turbo 项目验证或原生 Windows/macOS 验证。公开证据只包含通用样例。
