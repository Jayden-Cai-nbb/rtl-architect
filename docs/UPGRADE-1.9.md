# 1.9.0：把数值意图接到 RTL 核验

1.8 解决了阅读布局的显式约束；本轮补上评审路线中的类型表达缺口。此前模型只能声明等宽 unsigned 运算，而真实 RTL 常包含负数、扩展、截断和移位。现在 Agent 可以说明每一步的位宽与符号，并用现有状态比较和仿真检查核验，避免把不同的数值行为画成同一种“运算”。

## 同一个表达式，贯穿阅读与检查

SignalValue 新增显式 cast：重解释、零扩展、符号扩展、截取低位；每次声明结果 width/signed。增加 `<< >> >>>` 和三种归约，同类型比较支持 signed。端点与拼接继续按 unsigned 位向量读取，混合 signed/unsigned 运算要求显式转换。旧模型不补类型字段，不改变语义 hash。

核心解析器推导类型、检查转换方向。图中依赖角色、状态更新表、Spec、监视器与有限单步比较读取同一 AST。监视器在每个表达式节点固定宽度和符号，防止外层赋值把“先溢出再扩展”偷偷变成“先扩展再相加”。Yosys 适配增加字级移位，并保留在输出缩窄前参与右移的高位。

Yosys 移位单元的符号及位宽处理依据随工具安装的 simlib.v 和 [官方单元文档](https://yosyshq.readthedocs.io/projects/yosys/en/stable/cell/word_binary.html)，再用实际展开与独立仿真核对。未支持的移位单元、X/Z、未知驱动及超预算仍 UNKNOWN。

## 能直接试的例子

[有符号缩放样例](../examples/typed-expressions/README.md) 提供 RTL、模型、显式映射、TB 和验证清单。`8'h80` 右移一位：算术结果为 −64，逻辑结果为 64。点击状态可以看见符号扩展与低位截取顺序；核验错误版本时能得到输入/旧状态反例。

新增 `check:expression-types` 纳入原有 check。它检查旧 hash、非法转换、依赖角色、有限函数与整数穷举、五状态真实 RTL，以及 25 个独立 HDL 表达式。两类故障同时要求状态比较 MISMATCH 和实际仿真失败，避免只有模型自洽。

实际执行见 [验证记录](../VALIDATION.md) 与 [本轮证据](evidence/1.9.0/README.md)。样例随附原生并排阅读约束和初始视野；基本几何、连接对应及展示约束通过，多路扇出仍有交叉和收起的线名，未声称完成用户可读性验收。

## 边界与下一步

这是显式二态数值规则，未实现完整 SystemVerilog 类型系统、四态求值、跨层级状态映射或任意时序等价。MATCH 仍只对映射状态的单步函数成立；as_built 通过仍是还原一致性。v2.0 的真实用户审阅效率与架构偏差对照实验尚未完成，不能拿本轮维护样例代替。

下一阶段优先在实际用户案例中记录不能表达的状态/类型及阅读障碍，按证据扩展跨层级映射，并测量一个真实变更从需求到检测的闭环。保持少量确定性工具和一份权威模型。
