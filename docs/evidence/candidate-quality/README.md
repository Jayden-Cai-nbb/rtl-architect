# 候选路径与图形质量检查

本轮从生成提示、候选 preview/登记、投影准备、走线/标签、质量反馈到页面阅读检查。没有增加另一份硬件模型，也没有改变 engine、IR schema、AST、批准或验证规则。

## 实际改动与理由

- `diagram-quality` 新增 `--task overview|state|full`、`--state ID` 和完整视图 `--mode architecture|microarchitecture|signals`。默认仍是完整架构视图，保留既有命令行为；网页默认总览必须显式对应。报告记录模型来源、hash、任务、模式、坐标来源和本次生成耗时。
- Worker 与 CLI/导出共用 `prepareDiagram`。任务投影使用会话坐标或自动排列；完整视图的保存位置不再因 ID 偶然相同而进入任务投影。显式 reading 仍校验 hash，完整保存位置仍优先；候选不继承已保存模型的布局。
- 质量记录增加每条真实关系的长度、端点曼哈顿距离、绕行量、原始连接 ID、依赖端点及聚合成员。最长五条供定位；绕行提示要求多走至少 256 图单位且达到直距的两倍。它们不是物理线长、时序或失败判据，未路由不能被当作短路径。
- 页面“框图检查”可点选长关系与隐藏名称；边选择现在也会高亮端点和关系，共用的同源名称保持可见。选择只改变样式，不改变可见范围、节点位置或路径。
- “更多操作 → 下载本图检查”导出正在显示的图及候选身份，`exportedAt` 是下载时间，不冒充生成耗时或视觉验收。
- 没有名称的依赖边不再参与文字排布，也不占用不可见标签框。已命名连线与共享路由机制保留。
- skill 的 `references/diagram.md` 与 `proposal-guide.md` 增加候选生成/反馈提示：先保证语义和成员，再比较同版本、层级、任务和布局来源，分别核对标签、拥挤与视觉结果。页面没有自动 AI 调用。

## 本轮测量

`before.json` 是改动前在当前代码基线上重新执行；`after.json` 是最终实现重新执行。每种图同时保留 SVG 与完整图 JSON。typed-expressions 的 full 使用示例原保存位置；其任务投影依据原有 reading；external-axis 没有保存布局。候选页面另用经 CLI draft 登记的临时候选，不能与这里的已保存模型测量混算。

另试验过固定节点后按长/短路径改变走线顺序，以及按可用位置分配标签。没有满足非退化约束的样例改善，最终没有纳入这些额外搜索。比如 external-axis/top 的短边优先试探将交叉 6 降到 3，却使无关共线重叠从 278 增至 412 图单位；typed 的试探会交换被隐藏的名称。不能把这些候选称为更好。

## 验证与限制

检查结果和实际页面结果见相邻日志与 `browser.json`。`quality.visualReview` 始终为 not_run；自动化执行和截图观察在独立记录中描述，不把工具几何结果改成用户阅读通过。

保留了第一次子进程被沙箱阻止的日志，以及维护脚本比较 JSON 时未考虑 undefined 被省略的失败记录；修正序列化断言后重新运行。它们不作为通过记录。

真实项目未自动提交或批准。候选生命周期的 commit/hash 冲突检查仅在自动清理的临时副本执行；浏览器候选只登记、查看和下载报告。长关系仍需用户选择阅读重点；没有自动推导功能组、协议、周期或综合后门级逻辑。页面截图不证明 RTL 功能或使用者阅读效率。

浏览器脚本的前两次尝试分别遇到水平 SVG 路径没有可见矩形、以及面板展开时 ReactFlow 短暂重测，保留 `browser-svg-wait-attempt.json` / `browser-resize-wait-attempt.json`。改为等待路径挂载、面板稳定后再比较；没有忽略页面错误或几何差异。

实际截图观察：候选身份和 partial/UNKNOWN 说明可见；总览的关系名称、方向和高亮能辨认。初次点选时自动展开的成员 JSON 挤占图形，已将该入口改为按需展开；完整成员不删减。typed 的 AST 锥仍需要横向平移，图中说明其来源为模型声明，不能视作综合后结构。外部双级图的长返回仍跨越主体，几何完整不等于无拥挤。

每次生成耗时记录在 before/after 的 elapsedMs 中，是本机单次测量，部分与维护检查同时运行；不作为稳定提速或 p95 结论。远端 CI、完整 check:workflow、器件时序与用户阅读效率实验本轮未执行。

最终 `build-final.log`、5 组 `check-candidate-final.log`、完整 `check.log` 与 `rtl.log` 均通过。完整检查后，默认收起成员详情的纯 UI 调整另做 build、相关检查和最终浏览器复核；没有把早一版截图当作最终结果。两份候选页面的报告与 CLI 相同、普通选择几何稳定、零页面异常；最终构建身份见 `validation.json`。1440×1000 窗口下，同时展开长线检查后的画布高度为 typed 332 px、external 400 px；成员按需展开。

重启临时服务返回的 resume 链接曾携带 `panel=work`，工作面板展开使画布高度断言失败，已保留定位截图的失败记录。最终按原 draft 候选入口去掉恢复面板参数后重新执行；工作面板与复杂详情同时展开仍会挤占阅读空间，需收起面板。工具没有为通过断言改写用户工作记录。

临时服务已停止，临时浏览器与工作区已清理；完整受保护文件摘要核对见 `protected-before.json` / `validation.json`。`browser-procedure.mjs.txt` 和 `measurement-procedure.mts.txt` 保存本轮临时验证过程，需要按其中临时目录在独立环境准备浏览器，不是项目测试框架配置。
