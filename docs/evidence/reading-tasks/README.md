聚合节点保留成员 ID；关系保留原关系 ID、原连接 ID、依赖端点及位域。内部关系、范围外关系和显式辅助折叠各有清单及展开入口。聚合关系使用空心箭头，不产生物理 netKey 或电气分叉点。普通选中只改变高亮和详情。
