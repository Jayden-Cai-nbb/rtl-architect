# 下一状态逻辑锥：引用共享与阅读操作

这是上一轮[有限逻辑锥实现](../state-cone/README.md)之后的独立优化记录。旧截图、曾经失败的展开竞态和旧验证记录没有覆盖成本轮结果。

## 改动与理由

- 同一作用域、模块、端点、实例索引与位切片完全相同，才共用显示节点。已声明局部组合信号的表达式只绘制一次；不同声明即使 AST 相同也保持独立。没有新增实例、删除物理连接或跨位域合并。
- 每个共用端点保存所有引用路径、消费者与该消费者的 dependencyRoles。每个消费者的关系边保留。内部表达式来自唯一声明，展示引用不是新硬件模型；不进行通用公共子表达式优化。
- 旧代码曾把任何使用 Q 的 RTL 单元输入标为 hold Q。现改为仅 `$mux` 数据端直接返回完整 Q 时标记 hold；其他运算显示 old Q，移位 B 端明确为 shift amount。输入/上游状态边界也计入顶部提示，不推断叶位名字或结果 signedness。
- 增加全图、阅读大小、缩放、状态/规则定位、直接依赖高亮与邻接节点跳转。选择、缩放、定位都复用当前几何；只有显式展开/收回改变投影。缩小间距不改变类型、更新顺序、规则或时序。

## 同源测量

从本轮修改前的源码和修改后的源码分别生成同一模型、同一展开范围。原始记录：[改前](before.json)、[改后](after.json)。两个版本 modelHash 完全相同。

| 示例 / 范围 | 节点前→后 | 展示依赖前→后 | 画布前→后 |
| --- | ---: | ---: | --- |
| typed-expressions / packed_value_q | 14→14 | 13→13 | 3130×1200 → 2558×1016 |
| state-updates / out_data | 21→20 | 20→20 | 4050×1800 → 3298×1344 |
| state-updates / 展开 out_valid | 35→26 | 35→29 | 4050×2800 → 3298×1580 |

展开后的六条内部重复依赖来自同一局部组合声明的重复绘制，现在只绘制该声明一次；两条消费者关系仍分别存在。脚本独立遍历 IR，检查每个已访问 AST 出现位置都在节点 origin 或 references 中可追溯。它还检查不同位切片与 AST 相同的不同声明不会合并。

生成时间为一次运行的观测值，不是稳定基准。本轮没有测得耗时改善，不把较小画布当作性能或阅读速度证明。

## 几何、标签与实际视觉

- 几何：两个 typed 模型锥逐线段检查不穿越无关节点；state-updates 默认与展开图检查节点不重叠、路由无 fallback。所有声明消费者与类型保留。
- 关键标签：[typed 逻辑锥](typed-cone.png)保留 sign_extend、算术右移、truncate [7:0] 的顺序与类型；[展开状态图](state-cone.png)可见共享 accept 的两处引用、分别连接到两个消费者，Q/D 和复位优先级仍明确。
- 阅读拥挤：画布更紧凑，但仍有交叉、长返回路径与多路共线；没有增加电气分叉点，也没有通过隐藏背景依赖来提高对比度。
- 实际浏览器：[typed 全图](typed-fit.png)、[state-updates 全图](state-fit.png)、[独立 RTL 观察](rtl-fit.png)。1440×1000 页面中全图适合定位，约 32% 的缩放不能替代逐字阅读。默认阅读大小、定位与详情用于看清局部，较长对话框仍需滚动。
- [浏览器断言](browser.json)：选择、缩放、定位前后节点坐标和所有路径相同；展开/收回通过，无页面异常，根工作区及样例模型/布局文件摘要不变。浏览器使用临时样例副本，未批准真实项目。

## 验证范围

[构建](build.log)、[专项检查](cone.log)和浏览器检查为本轮执行。专项包含 256×16 输入穷举、规则优先级、所有 AST 路径追溯、声明身份负例、位切片负例、Q 运算与保持区分、移位角色、边界计数，以及两个样例的新 Yosys 观察。未知/未支持/过期/MISMATCH 继续保留。

本轮 `npm run check` 在完成 feedback、进入 assurance 时收到终止信号，以 143 结束；原因未确定，原始[中断日志](check.log)保留，不能称这条命令完整通过。随后从 assurance 起，按照 package.json 的原顺序执行全部剩余阶段，整体退出 0，见[续跑日志](check-rest.log)。因此每个检查阶段本轮均已完成通过，包含新增的不同声明身份负例。之后的 [rtl:test](rtl.log) 退出 0；它只验证 tiny-stream 初始 fixture，不证明任意模型一致性。

回归完成后，仅补充缩放按钮的上下限禁用状态，防止全图比例低于 10% 时点击缩小反而放大。对此重新构建并复查临时浏览器，包含低比例全图操作；记录最终构建摘要与几何不变断言。源码语义、AST 投影和路由在回归后没有变化。

RTL 观察继续只读取已有产物，没有新 HDL parser；产物没有统一结果 signedness 时仍显示 UNKNOWN。模型 AST 图不是综合门级结构，两种图均不证明完整顺序等价。远端 CI、发布检查和 `check:workflow` 本轮未执行。

最终状态见 [validation.json](validation.json)。两个临时页面服务已[停止](cleanup.log)，浏览器安装与样例副本已清理；中断 assurance 的临时 fixture 也已确认身份并清理，其运行记录保留在 [interrupted-assurance](interrupted-assurance/run.json)。未批准真实项目，未修改根目录或样例权威模型/布局。
