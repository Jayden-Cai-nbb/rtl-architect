表达式检查包含：旧模型 hash 不变、非法/混合类型拒绝、依赖角色、4096 组整数参照的四位移位与超大移位量、25 个独立 HDL 表达式各 4096 组输入，以及两种 RTL 故障。算术右移错成逻辑右移、signed 比较错成 unsigned 均要求 BDD 给反例且 Verilator 监视器失败；正常仿真不是唯一验收条件。
